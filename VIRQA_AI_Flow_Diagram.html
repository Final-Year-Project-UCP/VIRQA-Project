0 System Overview

VIRQA is an end-to-end AI interview automation platform. Employers schedule technical interviews, candidates are invited via email, and the system conducts live voice/text AI interviews with real-time scoring, adaptive difficulty, and role-specific result dashboards.

1 Technology Stack

⚛️

Frontend

React 19, Vite 7, React Router 7, TanStack Query 5, Tailwind CSS 4, Framer Motion, Chart.js, Axios

🔌

Real-time

Socket.io 4 (client + server). Notification rooms via join(userId). Interview rooms via socket.join(interviewId)

⚙️

Backend

Express 5, Mongoose 8, Multer uploads, JWT + bcrypt, ES Modules, HTTP server on port 8000

🤖

AI — Groq API

OpenAI-compatible SDK. LLM for conversation, evaluation, batch questions. Whisper for STT. Streaming via ai-response-chunk

🗄️

Database

MongoDB with Mongoose discriminator pattern: User → Candidate, Employee, Admin

☁️

External

Cloudinary (profile photos, resumes), Brevo SMTP API (invites, OTP, employee activation)

2 Roles & Frontend Portals

Three Mongoose discriminators on the base User model. Frontend route guards via ProtectedRoute.

🛡️

Admin

System-wide audit, employee management, global stats, feedback oversight. Login role: admin

👔

Employee (Institute)

Creates interviews, views evaluations, manages candidate pipeline. DB role: employee. Login tab: "Institute"

👤

Candidate

Takes AI interviews, manages profile, views results (if enabled). Auto-created on interview invite — no self-registration

8 Phase 6 — Answer Processing Pipeline

Input: Voice (send-audio) or Text (send-message)  |  Evaluation runs in background — does not block next AI turn 
flowchart TD
    START(["Candidate Responds"]) --> MODE{Input mode?}

    MODE -->|"Voice"| REC["MediaRecorder → webm ArrayBuffer"]
    REC --> AUDIO["emit send-audio"]
    AUDIO --> STT["sttService — Groq Whisper large-v3
temp file → transcribe → cleanup"]

    MODE -->|"Text"| TEXT["emit send-message message"]
    TEXT --> STT2["Use message directly"]

    STT --> TRANS["emit transcription-result"]
    STT2 --> TRANS
    TRANS --> SAVE["Push to AIInterview.answers[]"]
    SAVE --> EVAL_BG["evaluateAnswer — background Groq LLM
JSON: semantic, technical, overall
feedback, strengths, weaknesses"]
    EVAL_BG --> EVAL_EMIT["emit evaluation-result"]
    EVAL_BG --> DIFF["adjustDifficulty on scores"]
    SAVE --> NEXT["emitInterviewerReply
stream next AI turn immediately"]
    NEXT --> LOOP(["Conversation continues"])
